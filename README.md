# retro-95

Um modo retrô para o Claude no estilo do Windows 95:

- fundo verde-azulado de área de trabalho;
- respostas do Claude em janelas cinza com borda em relevo e barra de título azul-marinho;
- suas mensagens num campo de texto branco "afundado";
- chamadas de ferramenta em caixinhas cinza com fonte monoespaçada;
- paleta de 16 cores dos anos 90;
- bipes de 8 bits opcionais (ligue o alto-falante na barra de título da sessão).

O tema aparece no app desktop e no celular do Claude. O terminal não desenha temas.

## Instalação

No prompt de uma sessão do Claude Code no terminal:

```
/plugin install retro-95 --marketplace viniciusbfv-afk/retro-95
```

Responda `y` para adicionar o marketplace e depois escolha o escopo (Enter para o escopo de usuário).

Pelo shell:

```bash
claude plugin install retro-95 --marketplace viniciusbfv-afk/retro-95
```

No app desktop, onde `/plugin` não funciona: clique no + ao lado da caixa de mensagem, depois em Plugins, em Add marketplace com `viniciusbfv-afk/retro-95` e, por fim, em Add plugin.
